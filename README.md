# Email Intelligence Dashboard

An interactive analytics dashboard designed to monitor email volume, identify operational trends, and compare year-over-year performance.

## Features

- Interactive email volume dashboard
- Monthly email trend analysis
- Year-over-year (YoY) comparisons for 2024–2026
- Business-level performance breakdowns
- Dynamic filters and KPI summaries
- CSV export functionality
- Power Automate JSON data integration

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Microsoft Power Automate
- Microsoft Outlook

## Data Workflow

Microsoft Outlook → Power Automate → JSON → Interactive Dashboard

The dashboard currently uses imported data snapshots rather than a live connection.

## Project Purpose

To provide a centralized reporting interface for monitoring email volume, comparing historical trends, and supporting operational workload analysis.
